# 📊 Superstore Sales Performance & Profitability Dashboard

## 📌 Project Overview

This Power BI dashboard provides an interactive analysis of sales, profit, customers, orders, and regional performance using the Sample Superstore dataset.

It helps business users identify top-performing categories, monitor monthly sales trends, analyze customer segments, and compare regional profitability.

---

## 🚀 Dashboard Features

- 💰 Total Sales KPI
- 📈 Total Profit KPI
- 🛒 Total Orders KPI
- 👥 Total Customers KPI
- 📊 Profit Margin KPI
- 📦 Sales by Category
- 📅 Monthly Sales Trend
- 🥧 Sales by Segment
- 🌍 Profit by Region
- 🏆 Top 10 Products by Sales
- 🎯 Interactive Slicers (Category, Segment & Region)

---

## 🛠 Tools Used

- Power Query
- DAX
- Microsoft Excel
